Detailed Description

Robot class for Box2D simulation. Creates the robot in the world. This acts as a container of the 2D robot body and stores the raw pointer to the body. Note that the default constructor creates an instance without a valid robot. Before using it it needs to be overwritten by a robot which has been created in its world.
