Detailed Description

Turns sensor events into motor outputs. This is an abstract task which has all common features of the derived classes such as attracion or avoidance. Input units are physical units. The Speed is in m/s. The angular velocity is rad/s. Output units are servo units (-1..+1). This must be created with std::make_shared.
